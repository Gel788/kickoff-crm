# Идеал взрослого пилота

**Цель:** лига проводит тур без Excel.

## Прогресс

| Блок | % |
|------|---|
| Ядро матчдня | ~98% |
| Реестр + сезонный лист | ~95% |
| Чек-листы + таймы | ~90% |
| Дашборды клуб/судья | ~90% |
| **Идеал пилота офлайн** | **~98%** |
