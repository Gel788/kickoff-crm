# UAT — чеклист пилотной лиги (10+ матчей)

Перед стартом:

```bash
cd apps/web
npm run db:setup
npx tsx scripts/seed-uat-matches.ts
npm run dev
```

## Матч 1–12 (повторить для каждого)

| # | Шаг | OK |
|---|-----|-----|
| 1 | Лига: матч в календаре, статус SCHEDULED → SQUADS_OPEN | ☐ |
| 2 | Клуб: заявка заполнена и отправлена | ☐ |
| 3 | Лига: заявки утверждены, lock | ☐ |
| 4 | Судья: чек-лист → свисток → LIVE | ☐ |
| 5 | Судья: гол, ЖК, замена (или офлайн-очередь) | ☐ |
| 6 | Судья: завершение → PROTOCOL_REVIEW | ☐ |
| 7 | Делегаты/судья: подписи | ☐ |
| 8 | Лига: закрытие → CLOSED, таблица обновилась | ☐ |
| 9 | PDF протокол скачивается, логотип лиги (если загружен) | ☐ |
| 10 | Дисциплина: карточки → бан (если применимо) | ☐ |
